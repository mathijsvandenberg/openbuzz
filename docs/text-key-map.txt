# A2D text key -> default.str line id
#
# The engine resolves these keys through a 32-bit hash in default.ndx whose
# function is not identified (29 named candidates, a 5.9M-combination sweep of
# the multiply-accumulate family, and an ELF CRC-table scan all came back
# empty). This table replaces it.
#
# It is valid for every locale: all four default.ndx files on the disc are
# byte-identical, so a given id denotes the same key in NET, FRA, GER and ITA.
# Only the strings behind the ids differ.
#
# Contains identifiers and integers only - no game text - so unlike the strings
# themselves this file can live in the repository.
#
# Ids are 1-based line numbers in BM1/Text/<LANG>/default.str.
#
# VERIFIED entries were matched by meaning, not position: each round's block in
# default.str is a short title followed by its prose lines, and the Dutch text
# identifies the round unambiguously (id 37 "WIE HEEFT DE BOM" = who has the
# bomb; id 51 "WAAR STOPT DE ZOEMER" = where does the buzzer stop; id 56
# "AFSCHUIVEN" = passing off).
